# Leaf Tikes · sitio web

Página provisional de Leaf Tikes: experiencias de juego guiado y estimulación temprana para bebés y toddlers de 0 a 3 años en Playa del Carmen.

Sitio estático (un solo `index.html` + imágenes en `img/`). No necesita compilarse: en Vercel se importa el repositorio con el preset **Other** y se despliega tal cual.
